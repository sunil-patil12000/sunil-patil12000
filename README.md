# Sunil Patil

**Full-stack engineer building AI agents and backend systems for healthcare.**

Bengaluru, India · [sunilpatil.tech](https://sunilpatil.tech) · [LinkedIn](https://www.linkedin.com/in/sunilpatil14/)

I work at Circle Health on US Remote Patient Monitoring (RPM) and Chronic Care Management (CCM) platforms, from event-driven data pipelines to LLM-powered clinical workflows.

## What I build

- **LLM agents** on the raw Anthropic SDK: tool-use loops with a dispatcher as the safety chokepoint, tiered read/write tools and human-in-the-loop approval gates
- **Voice AI** for patient outreach: Twilio SIP trunking with Retell and Vapi agents, plus latency and turn-taking debugging
- **Event-driven pipelines** on AWS SQS, S3 and EventBridge: clinical-notes delivery, review state machines and billing triggers
- **PostgreSQL performance**: index strategy, query rewrites and Knex migrations for high-traffic endpoints
- **EHR integrations**: FHIR APIs, plus Playwright-based extraction for platforms without APIs

Most of this work lives in private repositories. Public projects are below.
